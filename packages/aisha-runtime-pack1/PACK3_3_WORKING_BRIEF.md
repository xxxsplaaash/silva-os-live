# Pack 3.3 — Response Posture Eval

## Goal
Turn the Pack 3.2 human review result into an explicit mode-evaluation layer.

## Modes to test
- Pure A
- Compressed B
- Full B
- Exploration Expand
- A/B Hybrid

## Required scenario classes
1. frustration + blocked action
2. breadth-heavy ideation
3. overwhelm + first-step request
4. urgent technical query
5. precision factual query
6. resistant / anti-therapy user

## Success condition
- eval output makes it obvious which posture wins in which context
- no universal "always Side B" assumption survives untested
- calibration/control case still exists
